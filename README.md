## 🧪 Task: Student Grades Analyzer

Write a Python program that does the following:

1. Prompts the user to enter the number of students.
2. For each student:
   - Ask for the **name**
   - Ask for the **score** (out of 100)
3. Store the data for all students in a list of dictionaries, like this:

```python
[
  {"name": "Alice", "score": 78},
  {"name": "Bob", "score": 92},
  ...
]
```

4. After collecting all the data, the program should:
   - Print the **average score**
   - Print the **name(s) of the student(s) with the highest score**
   - Print the number of students who **passed** (score >= 50)
   - Print the number of students who **failed**
