---

## 🧪 Task: Student Grades Analyzer (Form Version)

Create a simple **HTML + JavaScript** program that does the following:

1. **Display a form** where a user can enter:
   - **Student Name** (text input)
   - **Score** (number input, out of 100)
   - A button to **Add Student**

2. Each time the user clicks **Add Student**:
   - The student name and score should be stored in a JavaScript array of objects like this:
     ```javascript
     [
       { name: "Alice", score: 78 },
       { name: "Bob", score: 92 }
     ]
     ```
   - The form inputs should be cleared, ready for the next entry.

3. Add a **"Show Results"** button that when clicked:
   - Displays:
     - The **average score**
     - The **name(s) of the student(s) with the highest score**
     - The number of students who **passed** (score >= 50)
     - The number of students who **failed**

---

## ✅ Bonus (Optional)

If you’re able to complete the main task successfully, you can go a step further:

- Show the student list sorted from highest to lowest score.
- Allow the user to delete a student from the list.
- Save the student data to the browser’s **localStorage** so it remains after refreshing the page.
